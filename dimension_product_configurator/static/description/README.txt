AVANT DE CAPTURER
-----------------
1. DESINSTALLER les deux add-ons (_cond et _bom) avant de capturer le
   module de base : sinon leurs onglets "Conditional Logic", "Add-ons" et
   "BOM Template" apparaissent, alors qu'un utilisateur du module gratuit
   ne les verra jamais. Les reinstaller ensuite pour leurs propres fiches.

2. Largeur de fenetre 1400 px environ, zoom 100 %.
